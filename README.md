# ProposalForge AI

ProposalForge AI is a small, public portfolio project that turns a job brief into a clear first proposal draft.

It is intentionally generic:

- no private product branding
- no production credentials
- no billing code
- no user database
- no copied Git history

## What It Shows

- Client-first proposal structure
- Form state and live preview
- Draft scoring
- Reusable copy blocks
- Clean responsive UI

## Local Preview

Open `index.html` in a browser.

## Safety Check

Run:

```bash
npm run check
```

The check scans this repo for private project names, common secret patterns, and accidental environment files.
